R1 entry for the [Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) competition on make.fun — a single-line warning label for a time machine, 120 characters or fewer.

## The entry

> WARNING: Do not kill your grandfather. Customer service cannot restore ancestors, timelines, or you.

The joke turns the classic grandfather paradox into a deadpan customer-service disclaimer: the hazard is real, the tone stays officially calm, and the punchline lands on the last two words.

## How it works

`main.ts` (Node stdlib only) reads `entry.txt`, validates it against the competition gate — UTF-8 text, 1–120 characters, not only whitespace, a single line — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
